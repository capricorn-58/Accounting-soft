SHOP MANAGEMENT SYSTEM - ANDROID APP INSTALL GUIDE (Roman Urdu)
====================================================================

SACHAI: Asal ".apk" file banane ke liye Android Studio + Google ka
software chahiye hota hai jo is system mein available nahi hai.
Lekin ek behtareen aur mashhoor tareeqa hai jise "PWA" (Progressive
Web App) kehte hain — is se aap ka software bilkul app ki tarah
mobile pe install ho jayega, apna icon home screen pe hoga, aur
internet na hone par bhi chalega (offline).

Is zip mein yeh files hain:
  - index.html   (aap ka mukammal software)
  - manifest.json (app ki settings: naam, icon, color)
  - sw.js        (offline kaam karne ke liye)
  - icon-192.png, icon-512.png (app icon)

------------------------------------------------------
STEP 1: In sab files ko FREE hosting par upload karein
------------------------------------------------------
PWA install ke liye zaroori hai ke files internet (https) par ho
(sirf mobile mein file kholne se icon to ban jayega magar offline
mode aur asli "app jaisa" tajurba nahi milega).

Sab se aasan FREE tareeqa — GitHub Pages:
  1. github.com par free account banayein (agar nahi hai)
  2. "New repository" banayein, naam den jaise "shop-app"
  3. Is zip ki teeno files (index.html, manifest.json, sw.js,
     icon-192.png, icon-512.png) us repository mein upload karein
  4. Repository ki Settings > Pages mein jaakar "Deploy from branch"
     select karein, branch "main" aur folder "/root" rakhein, Save
     karein
  5. 1-2 minute baad aap ko ek link milega jaise:
     https://yourusername.github.io/shop-app/

  (Agar yeh khud karna mushkil lage to mujhe bata dein, main
   step-by-step aur bhi tafseel se samjha sakta hoon)

------------------------------------------------------
STEP 2: Android mobile par install karein
------------------------------------------------------
  1. Mobile mein Chrome browser kholein
  2. Upar wala link (https://yourusername.github.io/shop-app/) open
     karein
  3. Chrome khud "Add to Home Screen" ya "Install App" ka option
     dikhayega (ya top-right 3-dot menu > "Install app")
  4. Install par tap karein — bas! Ab aap ke phone ki home screen
     par "Shop MS" icon aa jayega, jese koi normal app ho.

------------------------------------------------------
Zaroori Baat: Data (Sales, Inventory wagera)
------------------------------------------------------
Yeh software data phone ke browser storage (localStorage) mein
save karta hai — jo isi phone aur isi app tak mehdood hoga.
Isliye HAR HAFTE apna data Excel/CSV export zaroor karein
(app ke andar jo export/backup feature pehle se maujood hai) taake
agar app cache clear ho ya phone tabdeel ho to data zaya na ho.

------------------------------------------------------
Agar hosting nahi karna chahte
------------------------------------------------------
Sirf index.html file WhatsApp/email se mobile bhej kar, "Files"
app se open karein aur Chrome mein khol lein — chalega, lekin
"install app jaisa" experience aur offline mode is soorat mein
kaam nahi karega, sirf normal browser tab ki tarah chalega.
